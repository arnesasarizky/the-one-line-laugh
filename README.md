## The line

> I asked my agent who broke production; it ran `git blame`, stared at my name for a full minute, and opened a ticket titled 'pre-existing condition.'

## How to run

Run `node main.ts` from the repository root. The program creates `/output` if needed and writes the line exactly, with no trailing newline, to `/output/entry.txt`.
